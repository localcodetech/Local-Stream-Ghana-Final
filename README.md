## Overview

**Local Stream Ghana** is the official corporate website and portfolio for **Local Stream Ghana**, a media technology company specializing in digital broadcasting, streaming infrastructure, software development, and cloud solutions.

The website showcases the company's services, projects, technology stack, client portfolio, and the professional portfolio of its founder. It is designed with a modern enterprise UI inspired by companies such as  Vercel and Cloudflare.

## Getting Started

Clone the repository.

```bash
git clone https://github.com/localcodetech/Local-Stream-Ghana-Final.git
```

Navigate to the project directory.

```bash
cd local-stream-ghana
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```

Preview the production build.

```bash
npm run preview
```
